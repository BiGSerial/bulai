# BULA-IA para Android

Aplicativo nativo (Kotlin) com as telas do PWA num WebView e alarmes exatos das doses, widget, atalhos, câmera, ditado e downloads.

```bash
scripts/preparar-ambiente.sh      # uma vez: JDK + Android SDK + local.properties
scripts/gerar-apk.sh              # APK de depuração em dist/
```

Arquitetura, API, permissões, assinatura e limitações: [`docs/app-android.md`](../../docs/app-android.md).
